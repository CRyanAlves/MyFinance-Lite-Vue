# MyFinance Lite

Aplicação de controle financeiro pessoal construída para demonstrar os principais recursos do Vue 3 em um seminário.

## Recursos demonstrados

- Composition API (`ref`, `reactive`, `computed` e `watch`)
- Componentes, props e emits
- Renderização condicional e listas (`v-if` e `v-for`)
- Formulários com `v-model`
- Estado global com Pinia
- Navegação com Vue Router
- Persistência com `localStorage`
- Tema claro e escuro
- Interface responsiva

## Como executar

```bash
npm install
npm run dev
```

Abra o endereço exibido pelo Vite no terminal.

## Gerar versão de produção

```bash
npm run build
npm run preview
```

Os arquivos finais serão gerados na pasta `dist`.
